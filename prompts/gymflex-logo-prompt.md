# GymFlex Logo Generation — Workflow & Prompts

Create a logo using company context + optional Pinterest reference. Same reference-first workflow as image prompts.

---

## Step 1 — Attach company context

Upload these files to a fresh ChatGPT chat (or any image AI with file support):

- `gymflex/gymflex-business-deepdive.md`
- `gymflex/gymflex-icp.md`

---

## Step 2 — Basic logo request (no reference)

```
I attached GymFlex's business deep dive and ideal customer profile.

Generate a logo for GymFlex.

Requirements:
- Brand name: GYMFLEX (or GymFlex — pick one consistent treatment)
- Tagline context: Recover. Reset. Repeat.
- Style: Modern, premium fitness apparel — comparable to Gymshark, Alo, Lululemon
- Clean and minimal; readable at small sizes
- Works on light and dark backgrounds
- Output: logo image with transparent background (PNG)
- No mockup scene — just the logo mark and wordmark
```

If it returns text only, say:

```
Generate an image of the logo (not just the prompt).
```

---

## Step 3 — Reference-based logo (Pinterest workflow)

1. Search Pinterest for logo styles you like (minimal athletic, bold wordmark, abstract mark, etc.)
2. Save 1–2 reference images
3. Open a **new chat**, attach business deep dive + ICP + reference image
4. Paste:

```
Use the attached image as a style reference and generate a logo for GymFlex.

I also attached the business deep dive and ideal customer profile — use them for brand direction.

Requirements:
- Company: GymFlex — premium fitness apparel
- Match the general style/structure of the reference (not a copy — inspired by it)
- Modern, athletic, premium, minimal
- Readable wordmark; optional simple icon or lettermark
- Transparent background PNG
- No product mockup, no scene — logo only
```

---

## Step 4 — Iterate until it fits

Try variations like:

```
Make the wordmark bolder and more compact for social media thumbnails.
```

```
Simplify the icon — fewer details, flatter design.
```

```
Use a monochrome version that works on both white and black backgrounds.
```

```
Remove gradients. Flat vector-style logo only.
```

---

## Example prompts by logo style

### Wordmark only

```
Generate a bold, modern wordmark logo for GymFlex. Sans-serif, athletic but premium. Black logo on transparent background. No icon. PNG.
```

### Icon + wordmark

```
Generate a GymFlex logo with a simple abstract icon suggesting flexibility/movement + the word GYMFLEX beside it. Minimal, premium fitness brand. Transparent PNG.
```

### Lettermark

```
Generate a lettermark logo using GF or G for GymFlex. Geometric, modern, premium athleisure brand. Transparent PNG.
```

---

## What to save

Once you get a result you like:

- Save the **transparent PNG**
- Reuse across ads, business cards, website, and course assets
- Keep the winning prompt for future variations (color, size, placement)

## Tool notes

- **ChatGPT** — good for logo drafts with context files + reference images
- **Pinterest** — reference hunting only; don't copy logos directly
- **Iterate** — first draft is rarely final; edit and regenerate
- Same rule as image prompts: **reference → analyze → customize → generate**
