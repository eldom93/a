# Better

A clean, modern, **zero-dependency** web starter — because a blank repo deserves better.

No build step. No `node_modules`. Just three files you can open in a browser and start editing.

## What's inside

- `index.html` — semantic, accessible markup
- `styles.css` — modern design system with CSS variables, dark/light themes, and responsive layout
- `script.js` — theme toggle (with persistence), scroll-reveal animations, and animated counters

## Features

- ⚡ **Zero setup** — pure HTML, CSS, and JavaScript
- 🎨 **Modern design** — gradients, fluid type, and tasteful motion
- 🌗 **Dark & light** — built-in theme toggle that remembers your choice
- 📱 **Responsive** — adapts from phone to ultrawide
- ♿ **Accessible** — semantic HTML, keyboard-friendly, respects `prefers-reduced-motion`
- 🚀 **Deploy anywhere** — works on any static host

## Run it

No server required — just open the file:

```bash
git clone https://github.com/eldom93/a.git
cd a
# then open index.html in your browser
```

Or serve it locally if you prefer:

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```

## Make it yours

Edit the content in `index.html`, tweak the color tokens at the top of `styles.css`
(`--brand-1`, `--brand-2`, `--brand-3`), and you're off.

## Deploy

Drop the folder onto any static host — GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.
There's nothing to build.
