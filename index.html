About

This repository was previously a README.md whose entire contents were the single character a. That's a fine placeholder, but a weird first impression. This starter replaces it with a small landing page you can actually open in a browser and then shape into whatever you need: a personal site, a project homepage, documentation, a scratch pad for ideas.

What's inside

  • Zero dependencies

    No npm, no bundler, no lockfile. Open index.html and it works.

  • Dark mode

    Follows your OS preference by default, with a toggle that remembers your choice in localStorage.

  • Accessible by default

    Semantic landmarks, visible focus rings, a skip link, and respect for prefers-reduced-motion.

  • Responsive

    Fluid typography and a layout that reads cleanly from a phone up to a wide display.

  • Modern CSS

    Custom properties for theming, logical properties, and color-mix() — no preprocessor required.

  • Easy to throw away

    Three files. Delete anything you don't like. There's nothing clever hiding anywhere.

Get started

  1. Clone the repo and open index.html in your browser, or serve the folder locally: 
    python3 -m http.server 8000
  2. Edit index.html to say what this project actually is.
  3. Tweak colors and spacing in styles.css — the theme is driven by CSS custom properties at the top of the file.
  4. Keep, extend, or delete script.js. The page works without it; it only adds the theme toggle and small niceties.
